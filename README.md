# Monitor COI v11.1

Monitor COI para analizar reportes COI de la Secretaría Distrital de Movilidad.

Incluye extracción de registros, filtros por empresas/contratos/estado/horario, dashboard, Excel/PDF y un **control referencial de menciones textuales** en el PDF.

La sección de control de menciones cuenta cuántas veces aparece el contratista y el contrato en el texto completo del PDF. **Puede incluir menciones en OBSERVACIONES, encabezados u otras referencias y por eso no debe interpretarse como validación exacta de filas.** Se usa como indicador para orientar la revisión manual.
