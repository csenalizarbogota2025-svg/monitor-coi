# Monitor COI v10.0

Aplicación Streamlit para analizar el Reporte Consolidado de Obras de Infraestructura (COI) de la Secretaría Distrital de Movilidad de Bogotá.

- Extrae todas las filas del COI mediante la geometría real de las celdas.
- Permite filtrar todas las empresas y contratos encontrados en el PDF.
- Genera dashboard, Excel y PDF con páginas originales.
- Incluye análisis por estado y horarios, incluyendo 24 HORAS.
